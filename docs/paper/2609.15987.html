한 줄 요약

BPO는 정책 최적화를 더 쉽게 만드는 새로운 방법입니다.

🧒 12살 버전 — 아주 쉽게

BPO는 게임을 할 때, 내가 어떤 선택을 했는지 보는 대신, 내가 끝에 도달했을 때 어떤 결과가 나오는지 보는 방법입니다. 예를 들어, 스포츠 경기에서, 내가 몇 번째에 어떤 결정을 했는지 보는 대신, 마지막에 승패가 결정된 결과만 보는 것입니다. 이렇게 하면 중간 과정을 따르지 않아도 됩니다.

💡 예시 — 이렇게 쓰여요

이 기술은 수학 문제를 푸는 데 사용됩니다. 예를 들어, 문제를 푸는 과정에서 중간 단계를 따르지 않고, 마지막에 정답이 나오는지 확인하는 방식입니다. 이는 문제를 푸는 데 더 빠르게 도움을 줍니다.

어떤 문제를 푸는가

대규모 언어 모델이 보상이 확인 가능한 환경에서 학습하는 데 어려움이 있었습니다. 기존 방법은 중간 상태의 가치를 추정해야 했고, 이는 계산이 복잡했습니다.

핵심 방법

BPO는 정책 미러 디센트(PMD)를 기반으로 한 비비판적 방법입니다. BPO는 벨만 방정식을 사용해 경로 수준의 목표로 문제를 재구성합니다. 이는 중간 상태의 가치를 추정하지 않아도 됩니다.

결과와 의의

BPO는 PMD와 동일한 최적 해를 제공하며, 수학적 추론 실험에서 효과적인 결과를 보였습니다.

📚 배경지식 — 알아두면 좋은 개념

강화 학습머신러닝의 한 종류로, 모델이 환경에서 학습하며 최적의 행동을 배우는 방법입니다.
벨만 방정식강화 학습에서, 현재 상태에서 최적의 행동을 선택하기 위해 사용되는 수학적 방정식입니다.
정책 미러 디센트정책을 최적화하기 위해 사용되는 수학적 방법으로, BPO의 기반이 됩니다.
비비판적 방법정책을 최적화할 때, 외부의 평가(비판) 없이 직접 학습하는 방법입니다.
중간 상태게임이나 문제 해결 과정에서, 시작과 끝 사이에 있는 단계를 의미합니다.

원문 초록

Reinforcement learning with verifiable rewards (RLVR) improves the reasoning capabilities of large language models (LLMs). We introduce Bellman Policy Optimization (BPO), a critic-free method derived from Policy Mirror Descent (PMD). For autoregressive generation with terminal rewards, BPO uses the Bellman equations to reformulate PMD as a trajectory-level objective. The reformulation avoids estimating state values at intermediate states. We prove that it has the same unique optimal solution as the original PMD objective. We derive the practical BPO loss by approximating this objective. Its mismatch-correction weight is a smoothed ratio of complementary token probabilities. Experiments on mathematical reasoning benchmarks demonstrate the effectiveness of BPO.
